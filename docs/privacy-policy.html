Политика конфиденциальности приложения LifeBalance

Последнее обновление: 8 марта 2026 г.

1. Ответственный за обработку данных

Обработку персональных данных осуществляет разработчик приложения LifeBalance. По вопросам персональных данных можно обратиться по контактам, указанным в разделе «Обратная связь» в приложении.

2. Какие данные мы обрабатываем

Данные Цель обработки Куда передаются
Адрес электронной почты (email) Регистрация, вход в аккаунт, восстановление доступа Firebase Authentication (Google)
Идентификатор пользователя (uid) Привязка и синхронизация ваших данных Firebase / Firestore (Google)
Текст заметок, целей, сфер жизни, аффирмаций Синхронизация между устройствами и подсказки на основе ИИ Firestore; наш сервер для анализа с помощью ИИ (обработка по запросу, без постоянного хранения)
Картинки Синхронизация между устройствами Firebase Storage (Google)
Язык и тема оформления Настройки приложения Хранятся на устройстве и могут попадать в резервную копию устройства

3. Правовые основания

Обработка осуществляется на основании вашего согласия (регистрация, использование функций синхронизации и ИИ) и для исполнения договора об использовании приложения.

4. Срок хранения

Данные хранятся, пока вы пользуетесь приложением и не удаляете аккаунт. После удаления аккаунта мы удаляем ваши данные с наших серверов в разумные сроки. Данные, отправляемые на сервер для ИИ-анализа, не сохраняются после формирования ответа.

5. Ваши права

Вы можете запросить доступ к своим данным, их исправление или удаление. Удаление аккаунта и связанных данных возможно через настройки приложения или по запросу на контакты поддержки.

6. Передача данных третьим лицам

Мы используем сервисы Google (Firebase Authentication, Firestore, Storage) для входа, синхронизации и хранения данных. Текст для ИИ-подсказок обрабатывается на нашем сервере; при запросе он не привязывается к вашему аккаунту и не сохраняется после ответа. С политикой конфиденциальности Google/Firebase можно ознакомиться по ссылке: firebase.google.com/support/privacy.

7. Безопасность

Используются защищённое соединение (HTTPS), шифрование локальной базы данных и ограничение доступа к данным по идентификатору пользователя.

8. Изменения политики

Актуальная версия всегда доступна по ссылке в описании приложения. Продолжая использовать приложение после изменений, вы соглашаетесь с обновлённой политикой.
