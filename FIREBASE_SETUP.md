# Настройка Firebase для LifeBalance

Для работы системы аккаунтов и синхронизации необходимо настроить Firebase.

**Важно:** Приложение может собираться и работать без Firebase, но функции аутентификации и синхронизации будут недоступны. Приложение будет работать только в офлайн режиме с локальной базой данных Room.

## Шаги настройки:

1. **Создайте проект Firebase:**
   - Перейдите на https://console.firebase.google.com/
   - Создайте новый проект или выберите существующий
   - Добавьте Android приложение с package name: `com.example.mylife.lifebalance`

2. **Скачайте google-services.json:**
   - После создания приложения, скачайте файл `google-services.json`
   - Поместите его в папку `app/` (на том же уровне, что и `build.gradle.kts`)

3. **Включите Firebase Authentication:**
   - В консоли Firebase перейдите в Authentication
   - Включите метод входа "Email/Password"
   - Включите метод входа "Google" (рекомендуется)
     - При включении Google Sign-In вам нужно будет указать название проекта и email поддержки
     - Firebase автоматически создаст OAuth 2.0 клиент
     - **Важно:** Скопируйте "Web client ID" (он понадобится для настройки приложения)

4. **Включите Cloud Firestore:**
   - В консоли Firebase перейдите в Firestore Database
   - Создайте базу данных в режиме тестового режима (для начала)
   - Выберите регион (например, us-central1)

5. **Правила безопасности Firestore (для тестирования):**
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```

6. **Добавьте SHA-1 отпечаток (ОБЯЗАТЕЛЬНО для Google Sign-In):**
   
   ⚠️ **Если вы видите ошибку `DEVELOPER_ERROR` или `SecurityException: Unknown calling package name`, это означает, что SHA-1 отпечаток не добавлен в Firebase Console!**
   
   **Получение SHA-1 отпечатка:**
   
   - Откройте терминал/командную строку в папке проекта `D:\LifeBalance`
   - Выполните команду:
     - **Windows:**
       ```
       gradlew signingReport
       ```
     - **Linux/Mac:**
       ```
       ./gradlew signingReport
       ```
   - В выводе найдите секцию `Variant: debug` и скопируйте SHA-1 отпечаток (строка вида `SHA1: XX:XX:XX:...`)
   - Пример вывода:
     ```
     Variant: debug
     Config: debug
     Store: C:\Users\...\.android\debug.keystore
     Alias: AndroidDebugKey
     SHA1: A1:B2:C3:D4:E5:F6:...
     ```
   
   **Добавление SHA-1 в Firebase:**
   - В Firebase Console перейдите в **Project Settings** (⚙️) → **Your apps** → выберите ваше Android приложение
   - Прокрутите вниз до секции **SHA certificate fingerprints**
   - Нажмите **Add fingerprint**
   - Вставьте скопированный SHA-1 отпечаток (без пробелов, формат: `A1:B2:C3:...`)
   - Нажмите **Save**
   - **Важно:** После добавления SHA-1 подождите 5-10 минут, чтобы изменения вступили в силу
   - Перезапустите приложение
   - **Для релизных сборок:** Добавьте также SHA-1 для release версии (получите через `gradlew signingReport` с release конфигурацией)

7. **Настройте Google Sign-In (опционально, но рекомендуется):**
   - Откройте файл `app/src/main/res/values/strings.xml`
   - Найдите строку `<string name="default_web_client_id">YOUR_WEB_CLIENT_ID_HERE</string>`
   - Замените `YOUR_WEB_CLIENT_ID_HERE` на ваш Web Client ID из Firebase Console
     - Web Client ID можно найти в Firebase Console → Authentication → Sign-in method → Google → Web client ID
     - Или в Firebase Console → Project Settings → Your apps → Web app → Web client ID

8. **Соберите проект:**
   - Убедитесь, что файл `google-services.json` находится в папке `app/` (на том же уровне, что и `build.gradle.kts`)
   - Синхронизируйте проект Gradle
   - Соберите приложение

## Без Firebase

Если вы еще не настроили Firebase, приложение все равно соберется и будет работать в офлайн режиме:
- Все данные хранятся локально в Room
- Функции аутентификации будут недоступны
- Синхронизация с облаком не будет работать
- При первом запуске приложение покажет экран входа, но вход будет невозможен без Firebase

После добавления `google-services.json` и настройки Firebase, все функции станут доступны.

## Методы входа

Приложение поддерживает два метода входа:
1. **Email/Password** - классический вход с email и паролем
2. **Google Sign-In** - быстрый вход через Google аккаунт (требует настройки Web Client ID)

Если Google Sign-In не настроен (Web Client ID не указан), кнопка "Войти через Google" не будет отображаться.

## Примечания:

- Приложение работает в гибридном режиме: данные хранятся локально в Room и синхронизируются с Firebase при наличии интернета
- При отсутствии интернета приложение продолжает работать в офлайн режиме
- **Автоматическая синхронизация:** Данные автоматически синхронизируются с Firebase при каждом изменении (добавление, изменение, удаление)
- **При входе в аккаунт:** Данные автоматически загружаются из Firebase
- **Восстановление данных:** После переустановки приложения войдите в свой аккаунт, и все данные будут автоматически восстановлены из Firebase

## ⚠️ Важно: Почему данные исчезают при удалении приложения?

**Локальное хранилище (Room):**
- Данные хранятся в локальной базе данных Room на устройстве
- При удалении приложения локальная база данных **полностью удаляется**
- Это нормальное поведение Android для безопасности данных

**Решение - синхронизация с Firebase:**
- Все данные автоматически синхронизируются с Firebase при каждом изменении
- После переустановки приложения:
  1. Войдите в свой аккаунт (Email/Password или Google)
  2. Данные автоматически загрузятся из Firebase
  3. Все ваши данные будут восстановлены

**Рекомендации:**
- Всегда входите в аккаунт перед использованием приложения
- Периодически проверяйте синхронизацию в настройках
- Убедитесь, что у вас есть интернет-соединение для синхронизации
