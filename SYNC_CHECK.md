# Проверка синхронизации с облаком

## Как проверить, работает ли синхронизация:

### 1. Проверка через логи Android Studio

1. Откройте Android Studio
2. Подключите устройство или запустите эмулятор
3. Откройте вкладку **Logcat**
4. Отфильтруйте логи по тегу: `SyncService` или `LifeBalanceViewModel`
5. Выполните действия в приложении (добавьте задачу, сферу и т.д.)
6. Проверьте логи - должны появиться сообщения:
   - `Starting background sync...`
   - `Uploading: X spheres, Y tasks, Z goals...`
   - `Background sync completed successfully`

### 2. Проверка через Firebase Console

1. Откройте Firebase Console: https://console.firebase.google.com/
2. Выберите ваш проект
3. Перейдите в **Firestore Database**
4. Найдите коллекцию `users` → ваш `userId` → `spheres`, `tasks`, `goals`, `ideaFolders`, `ideaNotes`
5. Проверьте, что данные появляются после изменений в приложении

### 3. Проверка через настройки приложения

1. Откройте приложение
2. Перейдите в **Настройки**
3. Нажмите на карточку **Синхронизация данных**
4. Должно появиться сообщение:
   - ✅ "Синхронизация завершена успешно" - если все работает
   - ❌ "Ошибка синхронизации: ..." - если есть проблема

### 4. Проверка восстановления данных

1. Создайте несколько задач, целей, сфер в приложении
2. Подождите несколько секунд (автоматическая синхронизация)
3. Или нажмите кнопку синхронизации в настройках
4. Удалите приложение с устройства
5. Установите приложение заново
6. Войдите в свой аккаунт
7. Данные должны автоматически восстановиться

## Когда синхронизация НЕ работает:

### Причины:
1. **Firebase не настроен** - нет файла `google-services.json`
2. **Нет интернета** - проверьте подключение
3. **Пользователь не авторизован** - войдите в аккаунт
4. **SHA-1 не добавлен** - для Google Sign-In (см. FIREBASE_SETUP.md)

### Как исправить:
- Проверьте наличие `google-services.json` в папке `app/`
- Убедитесь, что вы вошли в аккаунт
- Проверьте интернет-соединение
- Добавьте SHA-1 отпечаток в Firebase Console (см. FIREBASE_SETUP.md, шаг 6)

## Автоматическая синхронизация:

Синхронизация происходит автоматически при:
- ✅ Добавлении сферы, задачи, цели, папки, заметки
- ✅ Изменении сферы, задачи, цели, папки, заметки
- ✅ Удалении сферы, задачи, цели, папки, заметки
- ✅ Входе в аккаунт (загружает данные с сервера)

## Ручная синхронизация:

- Откройте **Настройки**
- Нажмите на карточку **Синхронизация данных**
- Дождитесь завершения синхронизации

## Логи для отладки:

Все операции синхронизации логируются с тегами:
- `SyncService` - основная логика синхронизации
- `LifeBalanceViewModel` - автоматическая синхронизация в фоне
- `SettingsScreen` - ручная синхронизация из настроек
- `AppNavHost` - синхронизация при входе

Ищите эти теги в Logcat для отладки проблем.
